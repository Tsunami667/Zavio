ZAVIO
=====
Fichiers de l'application (à mettre à la racine du dépôt GitHub Pages) :
- index.html, manifest.webmanifest, sw.js : l'application
- icon-*.png, apple-touch-icon.png : icônes

Mise à jour d'un site déjà en ligne :
1. Dans ton dépôt GitHub, clique sur « Add file » > « Upload files ».
2. Glisse les fichiers de ce dossier (ils remplacent les anciens), puis « Commit changes ».
3. Attends 1 à 2 minutes. Sur l'iPhone, ferme et rouvre l'appli 2 fois pour voir la nouvelle version.

Sauvegarde : Réglages > Sauvegarde > Copier (à coller dans une note). Restauration : Réglages > Restaurer.
